# VK 自动校准参数

从主窗口「硬件 → 校准」进入。VK 自动校准使用应用根目录（`DEFAULT_DIR`）下的 `ui/ui_config/ve_calibration_range.txt`，路径不随当前工作目录变化。开发运行和部署使用相同的相对位置。

默认完整内容：

```text
sample_rate=48000
range_volts=2.5
```

`sample_rate` 的单位为 Hz，必须写十进制整数，允许 4000–102400（含两端）。例如 `44100`、`48000`、`51200`、`96000`；小数、科学计数法、布尔值、零、负数和越界值均无效。

`range_volts` 的单位为 V，填写正的满量程电压，只允许 `10`、`5`、`2.5`、`1`、`0.5`、`0.1`、`0.02` 七档，分别表示对应的对称量程。例如 `2.5` 表示 −2.5 V 至 +2.5 V；数值相等的 `2.50` 也有效，不会自动选择最近档位。

文件使用 UTF-8（支持 BOM），两个键必须各出现一次，顺序可调整。允许空白行以及行首、行尾和等号两侧的空白。不支持注释、单位文字、节名、未知键、重复键或单行裸数值 `2.5`。

每次点击自动校准时读取一次完整文件，同一窗口内修改后下次点击立即生效，无需重启。已经启动的请求冻结本次采样率和量程；期间修改、删除或损坏文件不会改变本次录音或保存结果，只影响下一次启动。校准仍固定十秒、一次一个物理通道、零起始裁剪；默认采集 480000 个样本。设备和通道沿用硬件选择，标准声压在校准窗口选择。

这些参数仅影响 VK 自动校准。正常录制继续使用工况参数，普通声卡校准仍使用原有 44100 Hz；手动编辑系数不读取此文件。已有有效系数仍可用于合法的正常录制采样率和量程，无需迁移。新校准记录保存本次实际使用的采样率和量程，不改写工况或设备档案。

只有整个文件不存在时才使用 48000 Hz、±2.5 V 默认值，程序不会自动创建或改写文件。文件存在但为空、缺键、格式或数值错误、编码错误或无法读取时，本次 VK 自动校准不会启动，也不会覆盖已有系数。提示会指向 `ui/ui_config/ve_calibration_range.txt`；修正为上面的完整示例、保存为 UTF-8 并确保可读取后，再点击校准即可重试。

启动参数和错误沿用校准面板已有的 `LogManager` / `default_logger` 日志通道；启动日志包含请求、设备、物理通道、实际采样率与量程，配置错误由现有错误边界记录一次。不新增日志通道或输出原始录音内容。

允许的采样率范围来自软件校验规则，不代表已验证所有真实设备支持这些采样率。本次通过 SDK 替身测试参数传递与资源切换，未进行真实硬件验证。设备拒绝配置或报告的实际采样率不匹配时，校准失败；程序不回退到工况参数，也不重采样或按量程缩放系数。本次交付包含源码、默认文本和说明，不包含现场重新打包、安装或部署；部署时应将该文本放在应用根目录的 `ui/ui_config` 子目录。
