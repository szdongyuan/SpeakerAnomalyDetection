# 统一原始音频波形显示

日期：2026-09-23

## 背景与授权

本设计延续对 PR #920 的代码研究及用户认可的分阶段建议。本次实现统一静态波形显示，修复密集视图的尾部尖峰遗漏；实时采集保持折线/峰值显示，完成后切换到自适应插值。用户此前要求不要合并 PR，该约束继续有效：允许独立实施和测试，不自动合并、推送或发布。

研究基线：develop `842bb02ae9ca053e3af91d1bb70ec0d200d3a45a`；参考 PR 提交 `26c222d014932b401db2f393f6c8784bf38de696`。主工作区现有 `ui/ui_config/analysis_default_config.json` 修改属于用户，必须保留并排除在本次提交之外。

## 目标与范围

所有现有原始音频时域观察入口使用同一个显示组件：

| 入口 | 接入点 | 目标行为 |
| --- | --- | --- |
| 激励预览 | `ui/stimulus_window.py` | 总览保峰，放大后局部重建 |
| 主页加载音频、录音完成后的单/多通道预览 | `ui/sequence/channel_plot_workspace.py`、`sequence_widget.py` | 每个通道复用相同组件 |
| 实时播录和纯录音 | `sequence_widget.py` 两条 chunk 路径 | 明确禁用 sinc，完成后恢复自动选择 |
| 音频裁剪及选择模板片段 | `ui/custom_ui_widget/audio_clip_extraction_dialog.py` | 同样的显示策略，保持原始样本裁剪 |

SPL、频谱、频响、THD、响度、阈值线和异物分析中的 dB 曲线维持既有语义，不套用音频 sinc 重建。校准界面当前不显示原始音频波形，本次不新增波形界面。

## 方案选择

采用 PR 的公共自适应波形组件并完善尾部保峰及遗漏入口。这样能复用现有 PlotWidget、通道布局和交互，控制改动范围。

备选方案一是在本次直接启用实时 sinc；不采用，因为现有逐块累计拼接及反复更新仍未优化，多通道 UI 开销缺少实测保证。备选方案二是同时重构采集缓冲和显示调度；不采用，因为这是可独立交付的录音架构改造，超出本次显示统一范围。

## 显示组件与数据流

以 `ui/adaptive_waveform.py` 为公共显示组件入口，沿用 `PlotDataItem` 接口和显式 `streaming` 状态。调用方提供原始一维样本和严格按采样率生成的时间轴；多通道由既有通道工作区逐通道传入。

原始音频 → 原始采样时间轴 → 公共显示组件 → 密集峰值显示或局部 sinc 路径。保存、裁剪及分析始终读取原始数据，不能使用显示降采样或插值结果。`xData`/`yData` 保持原始样本；既有基于原始数据的导出入口不得改为导出重建数据。

### 密集视图

使用按显示分辨率选择密度的 min/max 峰值显示，保持尖峰，不以简单抽点或平均值替代。必须处理不足完整桶的最后一段；不能通过截去尾部来凑整桶。首尾单样本脉冲、负脉冲及最后一个不完整桶内部的脉冲都须保留。

当前 PyQtGraph 0.13.7 的 peak 路径会使用 `len(x)//ds` 后截去余数。本次在公共波形组件内局部解决，不修改第三方安装文件、不全局 monkeypatch、不强制升级依赖。实现可在规划阶段选择适配方式，但必须保留原始数据、可见范围裁剪和自动纵轴行为，不靠关闭全部降采样解决性能问题。

### 放大视图

沿用归一化 64-tap Lanczos 窗 sinc，只重建可见区域及所需邻域。文件外采用常值端点延拓。它是显示用有限重建，允许样本间峰值和振铃，不改变判定结果，也不代表测得的模拟真实峰值。

沿用 PR 的模式迟滞：采样点间距达到 2 像素时进入重建，已进入时低于 1.5 像素退出；达到 4 像素时显示原始样本标记。可见原始样本上限 4096；显示网格最多 8192 点，合并原始采样点后总重建点数最多 12288。工作量不得与整段文件的样本数成比例增长。

2026-09-23 用户预览后的显示调整：用户要求不必放大很多就能看到采样点，因此标记阈值从 12 像素降低到 4 像素（与现有 4 像素点径相当）；在同一窗口中可观察约三倍宽的时间范围后仍显示采样点。保留总览峰值降采样和可见区域裁剪，未要求恢复原 PR 的总览绘法。4 像素以下隐藏标记；标记仍只表示原始样本，且仅在静态重建有效时显示。实时录音、无效数据和清空时不显示这些标记。此调整由公共组件应用到激励、主页和裁剪预览，不新增配置项，不改变插值阈值、原始音频或数据格式。

数据、可见范围或尺寸变化时使相应缓存失效；范围和数据未变时复用重建。自动纵轴包含当前可见重建峰值。保留现有缩放、平移、颜色、通道布局和样本显示单位。

### 降级与生命周期

空数据、单点、局部 NaN/Inf、非均匀采样及 FFT/log/derivative/phasemap 等不支持的映射不执行 sinc，保留普通绘图语义；非有限值不能被插值连接成虚假连续信号。组件清空、移除、重新添加或 resize 后不得遗留路径、样本标记或抛出 Qt 回调异常。

实时播录与纯录音的每次数据更新均显式使用 `streaming=True`；即使用户放大也不得调用插值函数。成功完成后，两条路径使用最终原始音频恢复自动显示。失败或取消仍沿用原有录音处理，不新增伪成功状态；下一次正常静态数据加载必须能恢复自动模式。

## 裁剪窗口与时间轴

裁剪窗口改用公共组件。激励、主页与裁剪视图的第 i 个样本时间为 `i / sample_rate`，最后一个为 `(N-1)/sample_rate`，不能使用 `linspace(0, N/fs, N)`。

裁剪选区、拖动、固定时长、取消及按既有规则从原始数组取样的逻辑保持兼容，不将屏幕插值点当作可导出的新增音频样本。既有单声道加载策略不变，不在本次增加多通道裁剪功能。

## Compatibility / Migration

- Backward compatibility: required
- Protected surfaces: 音频样本、分析输入及判定、配置键、WAV/其他保存格式、数据库、裁剪索引规则、窗口交互、通道可见性、绘图调用方既有参数
- Allowed breakage: 无数据/API/格式破坏性变更；预期可见变化限于放大后的重建曲线、采样标记、包含重建峰值的自动纵轴、尾部尖峰恢复和正确的采样时间坐标
- Migration strategy: none

## 性能边界与验证

本次不承诺任意机器、通道数下的实时帧率，不增加录音过程 sinc 计算。当前全量累计拼接和每块数据触发更新的性能限制属于既有问题，本次不重构。

数值验证：覆盖 0.05/0.25/0.4 周期每样本与多个相位，内部正弦重建最大绝对误差低于 0.005，原始采样位置还原误差满足既有 `1e-12` 绝对容差；检查常值、短数据及边界。

绘图/集成验证必须覆盖：

1. 首部、中部、尾部及不完整尾桶正负脉冲；整段总览与末尾缩放下保峰，纵轴不隐藏峰值。
2. 密集/稀疏切换、resize、平移、重复刷新缓存、样本标记、自动纵轴和非有限数据降级。
3. 两条实时路径的插值调用计数为零；完成后自动恢复；重新加载及清空不遗留状态。
4. 激励、主页单/多通道和模板裁剪入口均使用公共组件，原始音频及选区导出不变。
5. 复跑 PR 涉及的自适应波形、通道工作区、录音元数据、录音流程、激励配置测试，并补充裁剪集成回归。

性能记录至少包括 48 kHz 下 10 秒和 60 秒源数据、1/4 个通道、约 800/1600 像素宽的代表性视图。分别记录密集 setData+绘制、放大平移+绘制、实时绕过和缓存命中的耗时，中位数/P95、环境版本、可见通道数及是否包含事件处理/绘制。比较同环境原始 PR 与改进版，报告可重复的退化及原因；不将纯数值耗时冒充完整 GUI 耗时。固定宽度及视野下，验证插值调用的输出点数/邻域大小不会随文件时长增长。

上轮数值检查通过，但 Qt 离屏运行曾异常退出。实施时必须先定位测试环境/回调退出原因，再获得实际 GUI 验证；如果仍无法完成，明确列为未验证事项，不宣称测试全部通过。没有真实采集硬件时明确保留硬件验收限制。
