# 激励预览按目标电压显示

## 用户问题与定位

用户明确报告：输出电压设置为 0.1 V，激励波形纵轴仍然约为 ±1，要求修复。主目录基线 `ff39fded979d5a20b9bdbe195d9fb0e99b4b5ade`。

已在实际 StimulusWindow 中复现：电压输入框和 stimulus_info.voltage 都为 0.1，graph_stimulus 仍直接绘制 stimulus_data，峰值约 1。传统 chirp/step 生成的是归一化形状；声卡播放另行应用校准 amplitude。电压类型切换当前仅更新元数据，外部 WAV 模式的电压编辑也不刷新图。

## 目标与边界

激励预览以设置的目标电压为单位显示原始样本形状及其显示用 sinc 曲线。纵轴标为“目标电压 (V)”以区分设定值对应的预览与实际硬件测量。修改数值或 RMS/Peak 类型均立即刷新。

适用于本窗口所有现有来源：chirp、step、frequency_stepped、noise、外部 WAV。主页采集波形和裁剪窗口无需做此单位换算。本次不继续修改采样点显示策略。

## 显示换算

完整源数组为 y，目标值为 V。换算只在独立显示数组上进行，不原地修改源。

- Peak：显示数组为 `y / max(abs(y)) * V`。
- RMS：显示数组为 `y / sqrt(mean(y**2)) * V`。统计基于完整波形，不能随当前缩放范围变化；包括现有淡出/静默段。
- 计算 RMS 时先除以最大绝对值，再求均方根，避免大数平方溢出。保留原有相位、符号、相对包络、样本数和时间坐标。整周期正弦设置 RMS 0.1 V 时峰值约 0.141421 V；Peak 0.1 V 时峰值 0.1 V。
- 已带幅度缩放的 frequency_stepped 数据按其实际统计量换算，不再次乘入声卡校准 amplitude。噪声及外部 WAV 采用同样的明确统计定义。
- 有效 V 必须为有限非负数；大小写不敏感的 RMS/Peak 可识别。0 V 显示零波形；空数据或全零数据保持空/零，不能产生 NaN 或除零。
- 缺失/非法 V、不支持的类型、含 NaN/Inf 的源或数值无法安全换算时，保留源幅度与有限连接间断，并明确标为“原始幅度”且不带 V 单位；不默默假设 1 V，不弹出重复模态警告。

显示单位转换是数据送入 AdaptiveWaveformItem 前的一步。峰值降采样、局部 sinc、真实采样时刻和 4 像素采样点阈值继续由共享组件处理；重建产生的样本间峰值可以高于采样值峰值，不对其额外截顶。

## 交互和数据流

图使用当前已同步的 stimulus_info.voltage/voltage_type。数值变化保持既有 calibration amplitude 更新/必要生成，然后刷新；外部 WAV 分支不重生成文件，只刷新显示。RMS/Peak 切换更新元数据并刷新，不修改源数组或对播放额外增益。初始化或恢复配置期间信号回调必须安全，不得使用尚未建立的控件或破坏已加载源。

## Compatibility / Migration

- Backward compatibility: partial（仅预览显示单位按用户要求改变）
- Protected surfaces: stimulus_data、音频/WAV 导出内容、播放参数与校准逻辑、配置/数据库结构、采样率、样本数、激励模式切换与原始外部 WAV 恢复行为
- Allowed breakage: 激励图纵轴数值/标签及图表数据导出的纵坐标随目标电压单位换算；旧测试中“图的 yData 等于归一化源”的断言须更新为电压换算断言，同时单独验证源保持不变。此前波形规格中的原始数据保护仍适用于音频源、分析及音频保存。
- Migration strategy: none

## 验证

1. 使用包含整周期正弦的实际窗口，复现设置 0.1 V 却仍显示 ±1 的失败；修复后 Peak/RMS 各有明确数值断言及单位标签。
2. 不改电压数值只切换 RMS/Peak，图立即变化；源数组及 amplitude 不因类型切换改变。
3. 外部 WAV 模式只修改电压，也刷新图；源和待保存/播放数组不变。
4. 带非单位幅度的 source（包含 frequency_stepped）及噪声遵循同一统计定义；零/空/非有限及非法元数据降级安全，缩放不改变统计基准。
5. 验证显示刷新前后的播放参数和音频保存输入保持原始约定，以 fake 音频后端验证，不触发硬件播放。
6. 复跑波形组件、裁剪、通道、激励模式/采样率、校准消费者及播放相关已有测试。保留已有用户分析配置修改。
